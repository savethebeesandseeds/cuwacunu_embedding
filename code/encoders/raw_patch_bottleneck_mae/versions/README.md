Copyright(c)2026 Waajacu. All rights reserved. Existing implementation notices are unchanged.

This is an additive metadata index of historical designs. Existing implementation, configs, checkpoints and frozen results stay at their original paths. These records make no new causal or forecasting claim and do not change primary RPB-v22 or balanced native36 selection.

Each numbered file is one design record. Training instances, dataset/scaler/geometry variants and checkpoints stay inside that record or its exact referenced registry. RPB-v3 keeps its registered label `RPB-v3-mean`; the numeric file is only an index slot. V24 native40 and native36 remain separate declared instances of the same design.

The [exact index](index.json) binds all30 files. Every source/config/evidence pin identifies its owning repository. Current headers and symbols are verified locators, not a claim that the current shared header is byte-identical to every old training definition. Older source/capsule or checkpoint gaps are explicit. No model ran and no archive was deserialized for this index.
